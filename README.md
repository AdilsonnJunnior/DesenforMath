# 📐 Plataforma Educacional de Geometria Sólida — DesenforMath

Uma ferramenta web interativa desenvolvida para auxiliar estudantes e professores na compreensão visual, espacial e matemática de formas geométricas sólidas.



## 🚀 Sobre o Projeto

O projeto integra tecnologia e educação ao conectar a teoria matemática à visualização prática. Os usuários podem manipular sólidos em um ambiente tridimensional, explorar sua planificação em 2D e acompanhar cálculos dinâmicos de área e volume em tempo real.



🚧 Status: O DesenforMath está atualmente em fase de desenvolvimento e testes. Algumas funcionalidades ainda estão sendo aprimoradas e podem sofrer alterações.



## ✨ Principais Funcionalidades

* **Visualização 3D Interativa:** Rotacione e examine os sólidos geométricos de diferentes ângulos.
* **Planificação de Figuras:** Compreenda a estrutura desdobrada de cada sólido.
* **Cálculos Dinâmicos:** Insira medidas e visualize instantaneamente as fórmulas, áreas e volumes.
* **Interface Moderna:** Design limpo e focado na experiência de aprendizado.



## 🛠️ Tecnologias Utilizadas

* **HTML5**
* **CSS3**
* **JavaScript**
* **p5.js:** Utilizado para a renderização e manipulação das visualizações 3D.



## 📦 Como Acessar

### 🌐 Online

Não é necessário instalar nada.

1. Acesse o [**DesenforMath — GitHub Pages**](https://adilsonnjunnior.github.io/DesenforMath/).
2. O projeto será aberto diretamente no navegador.
3. Pronto! Você já pode explorar as visualizações 3D, planificações e cálculos.

### 💻 Offline

Para utilizar o projeto sem internet:

1. Acesse o [**repositório do DesenforMath no GitHub**](https://github.com/adilsonnjunnior/DesenforMath).
2. Clique no botão **Code**.
3. Selecione **Download ZIP**.
4. Após o download, extraia o arquivo `.zip` em uma pasta do computador.
5. Abra a pasta do projeto.
6. Localize o arquivo `index.html`.
7. Abra o `index.html` em um navegador.

> 💡 **Dica:** Não é necessário ter uma conta no GitHub para baixar e utilizar o projeto.
